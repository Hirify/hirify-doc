Une fois un profil repéré, Hirify vous prépare un brouillon de prise de contact appuyé sur ce que son entretien a réellement montré. Vous le relisez, vous le corrigez, vous le copiez dans votre outil d'envoi.

## Où le trouver

Ouvrez le dossier d'un candidat depuis les résultats d'une recherche, puis cliquez sur **Rédiger un message**, en bas du volet de droite.

<Note>
  Le bouton n'apparaît que pour un candidat rattaché à un entretien analysé. Sans entretien, il n'y a rien sur quoi ancrer le message, et Hirify ne propose pas d'en inventer un.
</Note>

## Régler le message

La fenêtre **Rédiger un message** affiche le nom du candidat, puis quatre réglages.

| Réglage | Choix |
| --- | --- |
| **Ton** | Chaleureux · Formel · Enthousiaste |
| **Canal** | Email · LinkedIn · SMS |
| **Intention** | Premier contact · Relance · Prochain tour · Offre · Refus · Nouvelles |
| **Destinataire** | Candidat · Hiring manager · Note interne |

Le canal change la forme attendue : un SMS ne se rédige pas comme un e-mail, et seul l'e-mail reçoit un objet. Le destinataire déplace le point de vue : **Note interne** produit un texte pour votre équipe, pas pour le candidat.

## Générer et relire le brouillon

Cliquez sur **Générer le brouillon**. Pendant la rédaction, le bouton affiche **Génération…**.

Le résultat arrive dans deux champs modifiables : **Sujet**, pour un e-mail, et **Message**. Relisez-les et corrigez directement dedans, la fenêtre reste ouverte.

Changer un réglage puis regénérer remplace le brouillon affiché. Si vous tenez à une version, copiez-la avant.

## Compléter et copier

Quand la rédaction a besoin d'une information que Hirify n'a pas, elle laisse un repère plutôt que d'inventer. Ces repères sont listés sous le message, dans **Champs à compléter**. Remplacez-les dans le texte avant d'envoyer quoi que ce soit.

Cliquez ensuite sur **Copier le message**. Le bouton passe à **Copié !** et vous collez le texte dans votre messagerie, votre outil de messagerie professionnelle ou votre logiciel de recrutement.

<Warning>
  Hirify n'envoie aucun message. Il n'y a pas de bouton d'envoi dans cette fenêtre : la seule sortie est la copie. C'est vous qui écrivez au candidat, depuis vos propres outils.
</Warning>

## Le même geste depuis l'Assistant

Vous pouvez aussi demander le brouillon en conversation : « Rédige un brouillon de message pour @Nom ». La carte **Brouillon de message** rappelle en une ligne le canal, l'intention et le ton retenus, puis affiche **Objet** et **Message**, modifiables, ainsi que la liste **À compléter avant envoi**. Le bouton **Copier le message complet** récupère l'ensemble.

Sous la réponse, des propositions comme **Reformule sur un ton plus chaleureux** ou **Adapte pour LinkedIn** remplissent le champ de saisie sans l'envoyer.

## Bon à savoir

- **Le brouillon s'appuie sur l'entretien du candidat** : signal, forces, disponibilité. Il ne va rien chercher ailleurs.
- **Rien n'est envoyé, rien n'est planifié.** Pas d'envoi différé, pas de séquence de relance.
- **Rien n'est enregistré dans votre logiciel de recrutement.** Le brouillon vit dans la fenêtre tant que vous ne l'avez pas copié.
- **Relisez avant d'envoyer.** Un message d'approche engage votre marque employeur : le ton, le nom et les faits cités méritent votre relecture.
- **Le refus est une intention, pas un ton.** Choisissez **Refus** dans **Intention** et laissez le ton décider de la forme.
